# Stage 2 Prompt — CLI AI or IDE AI

**Works in:** Claude Code, Gemini CLI, Codex CLI, Aider (CLI), 
or Copilot / Cursor / Gemini Code Assist chat (IDE).
Open the project folder first, then paste the prompt.

---
I have a JSON file at `data/flashcards.json` that was generated by a Chat AI. 
The script `validate.py` already checks that the file is formatted correctly. 

I need you to build `quiz.py`, a terminal flashcard quiz app, using ONLY the Python standard library. Follow these rules exactly:

1. **Load and validate:** Import `load_deck` and `validate_deck` from `validate.py`. Load the deck. If it is invalid, print the errors and exit with code 1.
2. **Quiz loop:** For each card, show the question. The user presses Enter to reveal the answer. Then the user types `y` or `n` to say if they got it right. If the user types `q`, quit immediately.
3. **Scoring:** At the end, print the score (correct / total and percent) and list the missed questions.
4. **Options:** Add these flags for the user:
   - `--difficulty easy|medium|hard`
   - `--limit N`
   - `--shuffle`
   - `--seed N` (so tests are repeatable)
   - `--list` (print all cards as a study sheet, no quiz)
5. **Structure:** Keep the logic in small functions (`select_cards`, `run_quiz`, `summarize`) so they can be tested automatically without human typing.

After writing `quiz.py`, write unit tests in `tests/test_workflow.py` using `unittest`. 
Run `python -m unittest discover -s tests` and fix anything that fails. 
Finish by running `python validate.py` and `python quiz.py --list` to make sure everything works.
